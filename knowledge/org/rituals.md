# Rituals: Governance Iteration

## Review Cycle
- **Weekly Review Sessions:** The core mechanism for updating ground rules.
- **Pilot Project Loop:** "Test and Adjust" phase where rules are applied to a real-world pilot agent before being generalized.

## Process
1. Pilot implementation $\rightarrow$ 2. Observation of friction/failures $\rightarrow$ 3. Weekly review $\rightarrow$ 4. Update ground rules.
