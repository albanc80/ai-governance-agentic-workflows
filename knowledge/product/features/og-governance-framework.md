# Feature: Enterprise O&G Governance Framework
**Status:** Shipped
**Priority:** Critical

## Description
A high-safety governance framework for agentic workflows in the Energy/O&G sector, centered on the "Zero-Trust for High-Impact" philosophy.

## Key Components
- Asset Criticality Matrix.
- Safety-Valve Protocol (PVS).
- 3-Tier HITL balance.
- Forbidden Actions List.

## Success Criteria
- CISO sign-off on Security rules.
- Zero "Forbidden Actions" executed in Pilot.
- 100% auditability of Critical Asset actions.
