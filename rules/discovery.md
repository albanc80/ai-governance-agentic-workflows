# Rules: Discovery & Validation

## Validation Cadence
- **Weekly Review:** Every Friday, the framework is reviewed against pilot project outcomes.
- **Quarterly Audit:** Full review of the Risk Register and Golden Dataset.

## Discovery Process
1. **Identify Friction:** Note where HITL Tier 3 creates operational bottlenecks.
2. **Hypothesize Fix:** Propose a rule change (e.g., moving an action to Tier 2).
3. **Test in Pilot:** Validate the fix in a controlled environment.
4. **Update Framework:** Commit the change to the rules directory.
